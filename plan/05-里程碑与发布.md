## 3. 发布流程（M6 执行序）

1. 交付面定稿（README / `plan/` / `SKILL.md` / 报告）→ 重生成样例 → 全量测试 → `build_catalog.py --check`
2. `plan/RELEASE-M6.md` 落盘（§一 tag 前事实；§二 tag 后追加骨架）
3. commit → 建远端 → push → **首推 CI**（预期至少一轮诊断，见 §4）
4. `git tag -a v0.1.0` → 从 **tag 树**构建附件 → `SHA256SUMS` → Release 上传
5. `gh release download` 回下载 → `sha256sum -c` → 与本地副本 `cmp`
6. tag 后追加提交写事实（run id / 下载件 sha256）
