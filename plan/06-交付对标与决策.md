### 4.2 未采用方向

| 未采用 | 理由 |
|---|---|
| Go 单二进制 | 判定逻辑不需要；会引入"工具链不在 PATH"的一整套环境成本 |
| 网页 / GUI | 本题是 CLI + Agent Skill 双形态（`plan/00` §2.1 已定），GUI 不增判定能力 |
| 加第六判定态表达 Windows 双视角 | 破坏五态封闭；且"视角"是平台轴上的属性，不是判定结果的性质 |
| 运行时解析 YAML | 违背零依赖；且 YAML 解析器版本差异会污染真值的字节口径 |
| 用实现产出生成 `expected.json` | 循环论证（R8） |
